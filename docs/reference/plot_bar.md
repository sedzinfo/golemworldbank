# Build an animated ranked bar chart

Plots one indicator's top `top_n` countries per year as a horizontal bar
chart animated over `Year` (a "bar chart race"): in every frame the bars
are re-ranked, so a country that overtakes another moves up. For a
smooth animation the value axis only grows (it follows the largest value
seen so far, so bars never jump back when the maximum drops), and a
country's missing years between two observed ones are filled by linear
interpolation (so it does not drop out of the ranking for a year and
come back). Each bar carries the country name and its value; the bar of
`country` is red so it can be followed through the race, and the current
year is printed large and gray in the bottom right corner. Only
positive, complete-case rows are kept. Returns `NULL` when fewer than
two rows remain after filtering.

## Usage

``` r
plot_bar(mfi, indicator, font_style, top_n = 20, country = NULL)
```

## Arguments

- mfi:

  Data frame of World Bank indicator values (long format, with
  `Country Name`, `Indicator Name`, `Year`, `value` columns).

- indicator:

  Character. Indicator name to plot.

- font_style:

  A `plotly` font list (e.g. `list(size = 20, color = "gray25")`)
  applied to the chart's layout.

- top_n:

  Integer. Number of countries shown in each year.

- country:

  Character. Country whose bar is drawn red (`NULL` for none).

## Value

A `plotly` htmlwidget, or `NULL` if there is not enough data to plot.
